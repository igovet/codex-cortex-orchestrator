# General result report example

Use this as a content guide, not a required structure. Replace placeholders with
observed task facts; omit irrelevant sections, add useful ones and change their
order when helpful. Never copy example placeholders or imply checks were run.
Every profile uses the common Markdown writer; this file defines no tool arguments.

## Example Markdown

```markdown
# Result: <short outcome>

<What was achieved, for whom, and what remains incomplete.>

## Work and evidence

- <Concrete change or finding, with a relevant path or report reference.>
- <Evidence supporting the result; distinguish observation from inference.>

## Verification

| Check | Observed result | Evidence |
| --- | --- | --- |
| <Command or inspection> | <Actual outcome, or not run and why> | <Working directory, exit result or bounded observation> |

## Documentation impact

<Affected guidance and updates, or an evidence-backed reason no update is needed.>

## Limits and next steps

<Remaining risks, unanswered questions and useful follow-up; say none only when supported.>
```
