# Current host compatibility

Use only capabilities advertised and observable in the installed Codex. Check live
schemas before depending on a feature. Do not require a new host, hypothetical APIs,
synthetic receipts or personal registry scans. Native subagents use collaboration;
app task tools are reserved for explicit user-owned task management.

Absent host attestations stay unverified/not_applicable under the documented
observational mode. They neither prove host enforcement nor replace actual outcome
evidence. Passive observation/logging failures must not stop useful work. Host
sandbox, permissions and approvals remain authoritative. Preserve real safety and
integrity constraints; uncertain action results cannot be promoted into success.

Retain exact public task/parent/worker/report/artifact correlation where observable.
Use only documented current-host alternatives and record their limits. Ambiguity,
replay, truncation or incomplete outcomes cannot support acceptance. Read private
task storage through public report interfaces.
